# Privacy

MathSearch collects no data.

- It requests no browser permissions and has no host permissions.
- It makes no network requests. The PDFs you open, the symbols you search
  for and the search results stay in your browser tab; nothing is sent
  anywhere.
- The only thing it stores is the two memory settings of its panel (the
  memory cap and when to release memory), as one value in the extension's
  own browser storage. It never leaves your computer and is removed with the
  extension.
- It has no analytics, tracking, advertising or accounts.

The source code is public, so this can be checked:
<https://github.com/yoonjunchan/MathSearch>.
