# Support

- **Bugs and questions:** open an issue at
  <https://github.com/yoonjunchan/MathSearch/issues>. Please say which
  browser and version you use, and, if you can, which symbol you searched
  for and what you expected to be found. Don't attach PDFs you are not
  allowed to share.
- **Security problems:** please report them privately with GitHub's
  "Report a vulnerability" button on the repository's Security tab, not in
  a public issue.

MathSearch is a personal project, so replies may take a few days.
